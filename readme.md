# Final Stand VR

**Fantasy Multiplayer VR Boss Battler**

Final Stand VR is a short, intense cooperative VR boss fight for Meta Quest headsets. 2–4 players take on the roles of Fighter, Ranger, Healer, or Wizard and must work together to defeat a powerful Rock-Golem guardian inside a circular temple arena. The game features real-time hand-tracked combat, free movement, and distinct class abilities. A match lasts approximately 5–10 minutes.

The project was developed as part of the Game Design and Development 2 course (TU Graz / TUM Joint Online Course) in summer semester 2026.

## Technologies Used

- **Engine**: Unity 6
- **Networking**: Photon Fusion 2 (SharedMode)
- **VR Framework**: XR Interaction Toolkit (keyboard + mouse) + Meta XR All-in-One SDK
- **Platform**: Meta Quest 2 / 3 / 3S (standalone)
- **Version Control**: Git
